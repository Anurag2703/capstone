# MINDVERSE

## 1. About the Project
    This project is an AI-driven mental wellness chatbot designed to provide empathetic, personalized responses to users experiencing emotional distress. It leverages Google’s
    Gemini model for natural language understanding and integrates a Bhagavad Gita verse recommendation system for spiritual guidance based on the user’s emotional state.

## 3. Purpose
    The goal of this chatbot is to offer an accessible, supportive, and culturally rooted mental health assistant that:
    - Listens to users with empathy.
    - Provides motivational or comforting responses.
    - Escalates critical cases for professional help.
    - Shares relevant Gita shlokas for inspiration and wisdom.

## 3. Future Scope
    - Multi-language Support for wider accessibility.
    - Voice-based Interaction for a more natural experience.
    - Advanced Sentiment Analysis using deep learning for accurate emotional detection.
    - Integration with Mental Health Professionals for real-time intervention.
    - Mobile App Deployment for on-the-go support.
